#Сайт-визитка команды ОБЖ

Одностраничный сайт-визитка команды для отборочного задания Всероссийского хакатона «Волга.ТОП» 2026.

Сайт знакомит с участниками команды, их ролями и навыками, показывает проекты и видеовизитку. Визуальная подача построена на розовой палитре, декоративных фактурах и изображениях, плавных переходах между секциями.

## Реализованное решение

- разделы: участники, «О нас», навыки, проекты и видеовизитка;
- избранные проекты Ксении: FinLake, Course Feedback Analyzer и AI Culinary Assistant;
- карточки участников с фотографией и переворотом по клику;
- белая обратная сторона карточек с именем, ролью, почтой и группой;
- навигация между секциями и контактные mailto-ссылки;
- адаптация макета под мобильные устройства, планшеты и компьютер;
- плавное появление секций, stagger-анимации карточек и параллакс при прокрутке;
- поддержка `prefers-reduced-motion`;
- видео о команде

## Технологический стек

- HTML5;
- CSS3, CSS Grid, Flexbox, 3D transforms и CSS animations;
- JavaScript без фреймворков;
- Nginx Alpine для контейнерной раздачи статических файлов;
- Python `http.server` — только для быстрого локального запуска без Docker.

## Архитектура

Проект — статический сайт без серверного API и базы данных. `index.html` содержит разметку и интерактивные зоны, `styles.css` — визуальную систему, responsive-правила и анимации, `script.js` — навигацию, Intersection Observer, scroll-параллакс и состояние flip-карточек.

При сборке Docker-контейнер копирует только необходимые для публикации файлы в Nginx. Исходные Figma-файлы, документы задания и локальные артефакты исключены через `.dockerignore`.

## Установка и запуск без Docker

Требуется Python 3.10+.

```bash
python -m http.server 8000
```

Откройте <http://localhost:8000/>.

## Запуск в Docker

```bash
docker compose up --build
```

Сайт будет доступен по адресу <http://localhost:8000/>.

Остановить контейнер:

```bash
docker compose down
```

Альтернативно:

```bash
docker build -t plavushchaya-site .
docker run --rm -p 8000:80 plavushchaya-site
```

Контейнер содержит healthcheck на `/` и запускается от непривилегированного пользователя Nginx.

```text
├── compose.yml             # запуск проекта через Docker Compose
└── .dockerignore           # исключения из Docker build context
```

## Использование искусственного интеллекта

В работе использовался OpenAI ChatGPT (GPT-5).

Цели использования: консультации по поводу анализа структуры проекта, доработки HTML/CSS/JavaScript, scroll-анимаций, а также проверка запуска и доступности ресурсов.

Так как искуственный интелект использовался в качестве консультанта и тестировщика промты были однотипными и похожими, включали слова: проверь структуру проекта, протестируй готовый сайт, оцени сайт/проект и его структуру, дай рекомендации по улучшению.

Избранные проекты Ксении

FinLake

AI-ассистент для университетских данных · командный хакатон на Байкале

Сервис преобразует вопросы на естественном языке в SQL с помощью YandexGPT, проверяет запрос перед выполнением в PostgreSQL и возвращает результат. Реализованы ролевой доступ, авторизация, история диалогов и ограничения SQL.

Стек: Python, FastAPI, PostgreSQL, YandexGPT, Docker Compose, HTML/CSS/JavaScript.

Course Feedback Analyzer

Анализ отзывов с ML · командный проект

Анализирует русскоязычные отзывы об IT-курсах: две модели TF-IDF + Logistic Regression классифицируют тональность и тему текста. Интерфейс Streamlit показывает статистику и проблемные аспекты курсов.

Учебный датасет синтетический; результаты не подтверждают качество на реальных отзывах.

Стек: Python, scikit-learn, pandas, Streamlit.

AI Culinary Assistant

Telegram-бот подбора рецептов · проектный практикум

Рабочий Telegram-бот подбирает рецепты из русскоязычной базы по доступным продуктам, предлагает варианты блюд и пересчитывает ингредиенты под число порций.

Ручной ввод продуктов реализован и проверен; распознавание по фото ограничено доступностью AI API.

Стек: Python, aiogram, SQLite, Telegram Bot API.
